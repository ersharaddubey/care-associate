# Android APK build

The installable debug APK is built by the GitHub Actions workflow
`.github/workflows/android-apk.yml`.

The workflow builds:
`android/app/build/outputs/apk/debug/app-debug.apk`

Download the `care-associate-android-debug-apk` artifact from the completed
GitHub Actions run. This is a test/debug APK, not a Play Store release build.
